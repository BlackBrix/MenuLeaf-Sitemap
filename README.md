# MenuLeaf Sitemap for Joomla 5 / Joomla 6

A lightweight, menu-based HTML and XML sitemap **system plugin** for Joomla 5.4.x and Joomla 6.2.x. No third-party libraries, custom database tables, scheduled jobs, external API requests or other 3rd-party-dependencies.

**Release status:** v1.0.1, validated on Joomla **5.4.10** and **6.2.0** on 2026-11-08. Both versions were installed and exercised on actual Joomla installations. This is a tested release, not a pending test candidate. Test results below describe observed behavior; they do not constitute a formal security certification.

## What it does

- HTML sitemap: inserts nested lists under menu-type headings, preserving the parent-child relationship of published, visitor-accessible Joomla menu items.
- XML sitemap: generates a UTF-8 Sitemap Protocol `urlset` with absolute URLs, escaping, deduplication and no invented modification timestamps.
- Only one sitemap is supported; no custom menu item types, admin management screens, image/news/video extensions, custom priorities or change frequencies.
- XML excludes external URL items, menu aliases, heading/separator items, menu-level `noindex` items and standard user/search functionality. It also adds published, public articles (even without a dedicated menu item), honoring their category visibility, publication dates and article-level `noindex`.
- **New configurable switch:** Include archived articles in XML sitemap (default **No**). When enabled, archived content articles are also submitted individually. Existing menu-based archive overview URLs remain in both modes. The HTML sitemap is unchanged.
- Menu items marked `noindex` are excluded. If multiple public menu items link to the same content article and any of them specifies `noindex`, **all** direct menu routes to that article and its automatically discovered URL are omitted. This is a conservative SEO policy; review it if you intentionally want distinct menu-level indexing policies.

## Install and configure

1. Install the `plg_system_menuleafsitemap-1.0.1.zip` via Joomla **System → Install → Extensions**.
2. Enable **System - MenuLeaf Sitemap**.
3. Create a standard published Joomla article (e.g. `Sitemap`) with this exact content:

   ```text
   {menuleafsitemap}
   ```

4. Create a Joomla menu item of type **Articles → Single Article**, pointing to the article. This replaces your old 3rd-party-sitemap HTML menu item and can use the same `/sitemap` alias after that old menu item has been unpublished or renamed.
5. HTML page: the resulting Joomla article, such as `mydomain.tld/sitemap`.
6. XML endpoint: `mydomain.tld/?menuleaf_sitemap=xml`. Submit this **full URL** in Google Search Console; exact UI behavior for query-based sitemap submission should be checked. Optionally reference it in robots.txt by `Sitemap: mydomain.tld/?menuleaf_sitemap=xml`.
7. Check that XML responds with `Content-Type: application/xml; charset=utf-8` and no Joomla template HTML.
8. Verify the XML URLs, counts, page accessibility and any search engine's acceptance before disabling/uninstalling 3rd-party-sitemap.

Plugin parameters: HTML token, XML query parameter key, and **Include archived articles in XML sitemap** (default No). The HTML output does not depend on the archived-articles switch.

## Security and SEO notes

- SiteMenu supplies already published and in-date menu items; the XML sitemap enforces guest view levels independently of any administrator login. Direct single-article menu targets must also pass the same public article/category access, publishing-window, archive and article-level `noindex` filters as discovered content.
- URL and text output is XML/HTML escaped; route URLs are generated by Joomla itself. HTML external links are allowed where present in Joomla menus; XML omits them.
- The XML sitemap covers Joomla content articles, but not every dynamically generated page or extension-specific content. It respects explicit article-level robots `noindex` in Joomla metadata, but does **not** detect custom canonical tags, redirects, web-server headers, third-party robots logic or category-specific custom SEO overrides. Audit actual rendered page headers before SEO sign-off.
- Article links are generated through Joomla\Component\Content\Site\Helper\RouteHelper and Joomla routing. Their canonical equivalence to the rendered page has to be tested (especially articles without dedicated menu items). The deduplication key is the final string URL, not content identity.
- URL filtering is scoped to public guest view levels, published categories and ancestors, published articles, and publication windows. Archiving status is independently configurable. XML generation is on-demand and may require additional processing for large archives.
- This plugin does not produce `<lastmod>`: Google recommends using it only when it reliably represents a real page update. Google ignores `<priority>` and `<changefreq>`.
- XML endpoint is generated dynamically, with a 5-minute public HTTP cache header; no public writable XML file is needed.
- The site plugin is designed for native Joomla 5.4 and Joomla 6.2 APIs. Compatibility behavior must be checked against the installed site configuration.

## Verified compatibility and regression evidence (2026-11-08)

The following results were recorded from real installations. Counts reflect the respective sites' content, not a guaranteed number of URLs for other installations.

| Verification | Joomla 5.4.10 (production) | Joomla 6.2.0 (test site) |
| --- | --- | --- |
| Install/upgrade to 1.0.1 | Successful | Successful |
| HTML sitemap | Previously validated, unchanged by 1.0.1 | Previously validated, unchanged by 1.0.1 |
| XML, archived content OFF | 377 unique URLs | 77 unique URLs |
| XML, archived content ON | 2,174 unique URLs | 137 unique URLs |
| Valid sitemap XML and duplicate URL check | Passed | Passed |
| Comparison with 1.0.0 | Exactly one removed URL, the deliberately deleted old 3rd-party-sitemap menu item (`/sitemap-old?view=html&id=1`); all others unchanged and in the same order | URL sets and order unchanged for both archive modes |
| Direct public menu item targeting a registered-only article | Not separately tested on this installation | Passed (test fixture 066 omitted) |
| Direct public menu item targeting an unpublished article | Not separately tested on this installation | Passed (test fixture 141 omitted) |
| Two public menu entries for the same article, one marked `noindex` | Not separately tested on this installation | Passed (all routes for article ID 1, "Mein erster Beitrag", omitted) |

On Joomla 6.2.0, 150 fixture articles covered: 65 publicly published, 5 registered-only, 60 publicly archived, 10 with article-level `noindex`, 5 unpublished, and 5 future-dated articles. The 65 published and 60 archived fixtures appeared only under their expected archive-mode conditions. Restricted, `noindex`, unpublished and future-dated fixtures were omitted.

With the three targeted menu tests active, the Joomla 6.2.0 archived-ON sitemap contained **136 unique URLs**, exactly one fewer than before testing: the suppressed "Mein erster Beitrag" URL. No extra URLs appeared. The reverse-order `noindex` toggle was **not** separately verified; the implementation uses a two-pass algorithm to avoid menu-order sensitivity.

## Further recommended tests

- Confirm that other SEO rules applied by third-party extensions (redirects, canonicals, HTTP robots headers) agree with your desired indexing policy.
- Check unusually large sites for response time and memory usage because XML is generated dynamically.
- Test additional atypical menu item types on sites that use them.

## Updates

v1.0.1 **does not register an automatic Joomla update server**. To upgrade, install a newer plugin ZIP via Joomla's extension installer. The manifest uses `method="upgrade"`, so future ZIP releases with the same plugin identity can upgrade the installed extension without uninstalling it. Merely publishing a new GitHub release does not notify Joomla automatically. An update server may be introduced in a later release once a stable public repository and a maintained update XML endpoint exist.
